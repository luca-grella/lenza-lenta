# Changes to the contracts in ARCHITECTURE.md (append-only)
[Content] `src/data/index.js` exports `loadData(ctx)` (also `init`, default): sets `ctx.data` and calls `ctx.i18n.addStrings(it, en)` itself (main.js calling it again is harmless). Besides the contract keys, `ctx.data` has: `items` (id → record of every kind) + `get(id)`, `fishById`, `npcById`, `questById`, `zoneById`, `baskets`, `lantern`, `boat`, `cosmetics`, `dishes`, `sideQuests`, `aquariumMilestones`, `dailies`, `decor`, `home`, `treasure`, `fishShadows`, `speakers`, `shops` (= `shopStock`), `constants`, `helpers`.
[Content] Every record has `kind` (fish|junk|bait|rod|reel|line|basket|lantern|boat|cosmetic|ingredient|dish|decor|home|recipe) and explicit `nameKey`/`descKey` (quests: `titleKey`/`goalKey`; npcs: `nameKey`/`roleKey`/`dialogKeys`). Use these instead of building keys. Junk names use `fish.<id>.name` like fish.
[Content] Item ids are prefixed: `bait_*`, `rod_*`, `reel_*`, `line_*`, `basket_*`, `lantern`, `boat_*`, `hat_*`, `collar_*`, `ing_*`, `key_moon_crystal`, `rec_*` (recipe) → `dish_*` (cooked dish), `decor_*`, `home_*`. Starter items have `owned: true`; `unlock: {quest}` hides shop items until that story step is done; `needs: {id: n}` = items consumed on purchase besides coins (boat_repair, home tiers).
[Content] Pure helpers in `src/data/helpers.js` (also on `ctx.data.helpers`): `biteTable({habitat, zone, phase, weather, baitId, luck, lantern, exclude, caught})` → weighted candidates incl. junk; `pickWeighted`, `rollSize(sp, r, sizeMult)`, `priceFor(sp, size)`, `baitMatches`, `specialOK`, `needMatches(need, id)`. Gameplay may use them or reimplement; the rules are explained in docs/BALANCE.md.
[Content] fish.model extras: `variant` (crayfish|lobster|shrimp|octopus|cuttlefish|seahorse; fall back to `shape`), `width`, `eye` (small|normal|big|none), `fins {dorsal, tail, pectoral}`, `features[]`, `glow` (hex), `transparent`. `length` = elongation factor (1 = typical), `height` = body depth / length. Legendaries carry `special {zones, times, weather, baits, lantern?}` = hard conditions.
[Content] Quest goal filters may use payload keys plus `phase`/`weather` (read from ctx at event time), `kind`/`rarity`/`habitat` (looked up from the item/species), `junk: false`, `sizeRatio` (dailies), `bait`. Please include `bait` (and `zone`) in the `fishing:catch` payload: daily `daily_rosa_bait` filters on it.
[Content] New events used by quest data: `treasure:open` {} (Systems, when the chest at POI `treasure` is opened with `junk_key`) and the pseudo-event `deliver` (dailies: talk to the NPC while holding the requested items). Story rewards set `save.state.flags` (`boat_repaired`, `cat_friend`, `lighthouse_lit`, `treasure_open`, `story_done`, `aquarium_complete`): World should light the lighthouse beam when `lighthouse_lit` is set.
[Content] NPC ids are `gino` (fishmonger, pescheria), `rosa` (bottega), `tonio` (falegname), `pina` (trattoria), `marta` (aquarium), `ettore` (lighthouse). NPC data references POIs `npc_<id>`, `bench_village`, `bench_lighthouse` and `forage_meadow`, each with a `fallback` POI from the guaranteed list. Speakers without a rig: `letter` (grandpa's letter, story step 1) and `cat` (the cat is named Biscotto / Biscuit).
[Content] Data i18n keys never collide with Core's: `habitat.*`, `rarity.*`, `phase.*`, `weather.*`, `behavior.*`, `buff.<stat>.name|desc`, `stat.*` (gear stat labels), `fish.*`, `item.*`, `recipe.*`, `npc.*`, `q.*`, `daily.*`, `zone.*`, `shop.*` (+ `shop.section.*`), `creature.*`, `aquarium.milestone.*`, `treasure.*`.
[Core] Boot paths in src/main.js: src/data/index.js (loadData(ctx) or default object), src/i18n/{it,en}.js (default flat objects), src/world/index.js, src/actors/fishModels.js, src/actors/player.js, src/actors/npc.js, src/actors/creatures/index.js, src/systems/index.js, src/ui/index.js — each exports init(ctx) (named export, default.init or default function); missing/throwing modules are skipped with a warning. Until World exists main.js shows a placeholder island (ctx.stage). If ctx.player.object exists main makes the camera follow it.
[Core] Loop: core callbacks are input.update at order -1000, time at 1, cameraRig at 40, quality watchdog at 1000; the frame is rendered after all callbacks (ctx.post.render()). Callback errors are caught and logged (max 3 + every 300th).
[Core] New bus events: `resize` {width,height,portrait,pixelRatio,aspect}, `time:hour` {hour,day,skipping}, `input:press` {name} (named buttons except action), `save:reset`, `gl:lost`, `gl:restored`. `time:phase` payload also has `prev`.
[Core] i18n: save.state.lang stays null until the player picks a language; `ctx.i18n.chosen` (bool) tells the UI to show the first-launch picker. Plural syntax `'{n} {n|pesce|pesci}'`; `i18n.has(key)`; a missing key falls back to the other language before returning the key.
[Core] time: `time.set(h, day?)`, `time.format()` → "HH:MM", `time.lighting({overcast})` / `time.lightingAt(h)` = shared time-of-day palette {sky, horizon, fog, sun, sunIntensity, hemiSky, hemiGround, hemiIntensity, sunDir, moon, night, daylight, warmth, sunElevation}. World should drive its sun/hemisphere/sky/fog from it so post grading and audio stay consistent.
[Core] input: extra named buttons `inventory` (I) and `quests` (Q); Shift = slow walk (mag 0.5); gamepad (left stick, A action, X interact, Y bait, Start menu, Back map); `press(name)`, `released(name)`, `isDown(name)`, `moveScreen`, `lastDevice`, `clear()`; `setAction(v, source='ui')` (several sources may hold it).
[Core] cameraRig: also `setShot({position, lookAt, fov})` (cinematic), `snap()`, `toScreen(vec3)`, `lookTarget`, `followPos`, `followed`, `yaw` (base yaw, default 0 = camera south of target looking north), `offset`, `wheelZoom`; exported CAMERA_MODES table in src/core/camera.js.
[Core] audio: music mood is automatic by default (`setMusic('auto')`): phase → day/dusk/night, rain/storm → rain, zone `sea_cave` (bus zone:enter) → cave; any explicit setMusic(mood) overrides until setMusic('auto'). Ambient birds/crickets/rain/wind are automatic (time + weather) until a module calls setAmbient on that layer (`setAmbient(layer,'auto')` gives it back); waves/waterfall/river are for World to drive by proximity. sfx opts add `delay`, `pan`; `audio.meter()` {rms, peak} dBFS; `audio.unlocked`, `audio.volumes`, `audio.mood`. Core unlocks audio itself on the first pointer/key gesture.
[Core] post: `post.auto` (default true) adds the time-of-day warmth/exposure/night tint; `grade()` also accepts contrast, split (split-toning), lift; `post.params` read-only; `post.setFocus(vec3|null)` (tilt-shift band centre, default = followed object).
[Core] quality: extra fields `bloom`, `msaa`, `tiltTaps`, `drawDistance` (0.6..1), `foliageDistance` (m), `particles` (0.4..1), `water` ('low'|'mid'|'high'), `setting` ('auto' or forced), `detected` {tier, reason, gpu, software, platform}, `stepDown()`. URL `?quality=low|mid|high` forces a tier. Core itself applies pixel ratio, renderer shadows on/off, DirectionalLight shadow map size and post on quality:change.
[Core] save: defaults include `meta` {created, saved, playSeconds} and equip {rod:'rod_bamboo', reel:'reel_basic', line:'line_cotton', bait:'bait_worm', hat:'hat_straw'} + owned for those + basket_small; also `save.firstLaunch`, `save.export()`, `save.import(json)`, `save.available`.
[Core] ctx extras: `ctx.viewport` {width,height,portrait,pixelRatio,aspect}, `ctx.params` (URLSearchParams), `ctx.isDebug`, `ctx.haptic(pattern)`, `ctx.ORDER`, `ctx.createTestStage(opts)` (placeholder lights/sky/island/water/dummy for sandboxes; sets ctx.stage), `ctx.audioAuto`.
[Core] debug (window.__lenza): also `ready` (Promise, resolves on bus 'game:ready' — sandboxes must emit it), `freeze()`, `advance(n)`, `snapshot()`, `quality(t)`, `info()`, `errors`, `logEvents()`. teleport uses `ctx.player.teleport(x,z)` when it exists, else moves ctx.player.object / the followed object.
[Core] tools: tools/lib.mjs (shared), tools/strip.mjs (animation contact sheets), shot.mjs now captures console.warn too and supports `shot(name)` inside scenarios; see tools/README.md.
- [Creatures] ctx.creatures also exposes species{id→controller}, setEnabled(id, true|false|null), active(), env, fx; every species controller has setActive/setCount/update/list/debugSpawn; dolphins emit bus 'creatures:dolphins' {x,z} when a pod appears (UI may toast creatures.dolphins). sandbox/creatures.html views: fish, thumbs, catclips, zoo (&night=1), island (&force=ids).

[World] world.setWeather(type, {instant, duration}) with type clear|cloudy|rain|fog|storm; world.weather = {type, intensity, wind:{x,z,strength}, rain, fog, cloud, overcast}; emits 'weather:change' {type, prev}; persisted in save.state.weather {type, until}.
