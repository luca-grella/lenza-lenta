# Changes to the contracts in ARCHITECTURE.md (append-only)
[Content] `src/data/index.js` exports `loadData(ctx)` (also `init`, default): sets `ctx.data` and calls `ctx.i18n.addStrings(it, en)` itself (main.js calling it again is harmless). Besides the contract keys, `ctx.data` has: `items` (id → record of every kind) + `get(id)`, `fishById`, `npcById`, `questById`, `zoneById`, `baskets`, `lantern`, `boat`, `cosmetics`, `dishes`, `sideQuests`, `aquariumMilestones`, `dailies`, `decor`, `home`, `treasure`, `fishShadows`, `speakers`, `shops` (= `shopStock`), `constants`, `helpers`.
[Content] Every record has `kind` (fish|junk|bait|rod|reel|line|basket|lantern|boat|cosmetic|ingredient|dish|decor|home|recipe) and explicit `nameKey`/`descKey` (quests: `titleKey`/`goalKey`; npcs: `nameKey`/`roleKey`/`dialogKeys`). Use these instead of building keys. Junk names use `fish.<id>.name` like fish.
[Content] Item ids are prefixed: `bait_*`, `rod_*`, `reel_*`, `line_*`, `basket_*`, `lantern`, `boat_*`, `hat_*`, `collar_*`, `ing_*`, `key_moon_crystal`, `rec_*` (recipe) → `dish_*` (cooked dish), `decor_*`, `home_*`. Starter items have `owned: true`; `unlock: {quest}` hides shop items until that story step is done; `needs: {id: n}` = items consumed on purchase besides coins (boat_repair, home tiers).
[Content] Pure helpers in `src/data/helpers.js` (also on `ctx.data.helpers`): `biteTable({habitat, zone, phase, weather, baitId, luck, lantern, exclude, caught})` → weighted candidates incl. junk; `pickWeighted`, `rollSize(sp, r, sizeMult)`, `priceFor(sp, size)`, `baitMatches`, `specialOK`, `needMatches(need, id)`. Gameplay may use them or reimplement; the rules are explained in docs/BALANCE.md.
[Content] fish.model extras: `variant` (crayfish|lobster|shrimp|octopus|cuttlefish|seahorse; fall back to `shape`), `width`, `eye` (small|normal|big|none), `fins {dorsal, tail, pectoral}`, `features[]`, `glow` (hex), `transparent`. `length` = elongation factor (1 = typical), `height` = body depth / length. Legendaries carry `special {zones, times, weather, baits, lantern?}` = hard conditions.
[Content] Quest goal filters may use payload keys plus `phase`/`weather` (read from ctx at event time), `kind`/`rarity`/`habitat` (looked up from the item/species), `junk: false`, `sizeRatio` (dailies), `bait`. Please include `bait` (and `zone`) in the `fishing:catch` payload: daily `daily_rosa_bait` filters on it.
[Content] New events used by quest data: `treasure:open` {} (Systems, when the chest at POI `treasure` is opened with `junk_key`) and the pseudo-event `deliver` (dailies: talk to the NPC while holding the requested items). Story rewards set `save.state.flags` (`boat_repaired`, `cat_friend`, `lighthouse_lit`, `treasure_open`, `story_done`, `aquarium_complete`): World should light the lighthouse beam when `lighthouse_lit` is set.
[Content] NPC ids are `gino` (fishmonger, pescheria), `rosa` (bottega), `tonio` (falegname), `pina` (trattoria), `marta` (aquarium), `ettore` (lighthouse). NPC data references POIs `npc_<id>`, `bench_village`, `bench_lighthouse` and `forage_meadow`, each with a `fallback` POI from the guaranteed list. Speakers without a rig: `letter` (grandpa's letter, story step 1) and `cat` (the cat is named Biscotto / Biscuit).
[Content] Data i18n keys never collide with Core's: `habitat.*`, `rarity.*`, `phase.*`, `weather.*`, `behavior.*`, `buff.<stat>.name|desc`, `stat.*` (gear stat labels), `fish.*`, `item.*`, `recipe.*`, `npc.*`, `q.*`, `daily.*`, `zone.*`, `shop.*` (+ `shop.section.*`), `creature.*`, `aquarium.milestone.*`, `treasure.*`.
